# headbangertycoon.com

Static site for the **Headbanger Tycoon** Android game, served via GitHub Pages
at [headbangertycoon.com](https://headbangertycoon.com).

Public on purpose — it holds only files that must be reachable on the open web:

| File | Purpose |
| --- | --- |
| `index.html` | Landing page |
| `privacy-policy.html` | Play Store / AdMob required privacy policy |
| `app-ads.txt` | AdMob authorized-sellers verification ([IAB spec](https://iabtechlab.com/ads-txt/)) |
| `CNAME` | Custom domain binding for GitHub Pages |

The game's source lives in a separate private repository.
